# Release v3.39.3

Released: 2026-09-21

## Highlights

- **Large Claude reviews can run without shell argument limits.** Complete review payloads now travel through a bounded, private stdin file while preserving the existing read-only tool restrictions.
- **Parallel reviews preserve optional OpenCode admission failures.** A denied provider remains visibly inconclusive without incorrectly blocking other reviewers or exposing raw provider diagnostics.
- **Release tags identify the published code.** New GitHub release tags point to the release commit used for npm publication.

## Fixed

- Preserve complete Claude review payloads, apply byte limits, and clean up temporary input after success, failure, or timeout.
- Keep OpenCode admission status separate for each parallel reviewer and finalize it after the shared working-tree restoration check.
- Pin automated release tags to the workflow commit instead of the repository's default branch.
