# Release v3.33.0

Released: 2026-08-18

## Highlights

- **Cursor Agent is a first-class `--review-with` reviewer.** `--review-with cursor` (alias `cursor-agent`) now runs the Cursor Agent CLI the same way grok, claude, agy, and codex already do — including model pinning and `~effort`.

## Cursor as a local reviewer

- New slug `cursor` (alias `cursor-agent`) on every command that already accepted the other local agents: `/do:review`, `/do:pr`, `/do:release`, `/do:better`, `/do:better-swift`, `/do:depfree`, `/do:rpr`, `/do:pr-better`, `/do:plan-task`, and `/do:config`.
- Model pinning uses the same bracket grammar as the other agents: `--review-with cursor[gpt-5]` or a saved `--review-models cursor=gpt-5`.
- Cursor has no `--effort` flag, so `~effort=<level>` is folded into the `--model` variant (`gpt-5[effort=max]`) instead of being dropped or passed as a flag the CLI would reject.
- Binary probe prefers `cursor-agent`, and only falls back to a PATH `agent` when that binary's `--help` identifies as Cursor — so Grok Build's own `agent` is not mistaken for Cursor.
