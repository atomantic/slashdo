# Release v3.38.3

Released: 2026-09-14

## Highlights

- **Commands start with far less context.** Branch-only lib partials — reviewer backends, audit lenses, issue-mode setup, swarm — load with `!read` at the step that needs them instead of being `!cat`-inlined on every run. Default-path context across all commands drops from ~1.95M to ~834K bytes (for example `/do:review` 323K→74K, `/do:pr` 266K→76K).
- **Heavier prompts are tighter.** The largest command files and review-loop partials drop restated rationale while keeping flags, error strings, shell blocks, tables, and headings, so a capable model still has the rules without the echoes.

## Changed

- Conditional lib partials now use `!read lib/<name>.md` at the gated step instead of eager `!`cat ~/.claude/lib/<name>.md`` (1371b68, c59a710).
- CONTRIBUTING documents when to `cat` vs `read` a partial: defer only content that is usually skipped, and say in the sentence before the directive exactly when it applies (c59a710).
- Contract tests resolve both `!cat` and `!read` so splitting a section into a deferred partial cannot hide it from the suite (1371b68).
- Prose-only trims of restated rationale in the heaviest command files and review-loop partials, including `next-swarm` and `plan-issue-mode` (96f7220, 505b8fa).
