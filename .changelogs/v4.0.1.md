# Release v4.0.1

Released: 2026-09-23

## Highlights

- **Prompts tuned for current Claude models.** Leftover wording written for older models is gone from the commands and shared partials. That includes lines that told the model to run steps "without narrating" and fixed sentence counts for review findings, which made current models too quiet or too terse. The rules themselves are unchanged.

## Changed

- Removed "without narrating" from the reviewer-loop probe steps, and removed the fixed length limits on review explanations and summary highlights.
- Rules are now stated as current fact instead of compared against older versions of the text ("legacy", "historical", "has always", "formerly documented", "no longer"). Old issue-number history is gone from the prompts.
- The review-model examples use the `claude[opus]` alias instead of a pinned model ID.
