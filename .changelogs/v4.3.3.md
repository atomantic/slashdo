# Release v4.3.3

Released: 2026-10-24

## Highlights

- **Expected release CI is no longer mistaken for a required check.** `/do:release` now distinguishes the release workflow that runs after the merge from the checks that gate the release PR, so a repository whose only CI is the post-merge release pipeline no longer stalls waiting for a check that cannot attach.

## Fixed

- Distinguish expected release CI from required checks in the release merge gate, via a new shared `release-ci-gate` procedure that is installed and uninstalled with the other libs.
