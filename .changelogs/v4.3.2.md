# Release v4.3.2

Released: 2026-10-24

## Highlights

- **Review local once per delivery.** `/do:pr` runs configured local reviewers once before opening a PR/MR and records a durable receipt, so feedback and CI-fix pushes continue PR-side handling instead of re-running local review.
- **Keep hosted review honest.** After a feedback commit, CI fix, or rebase changes the head, hosted reviewers run against the current head; an old local verdict never justifies skipping them.
- **Resume safely.** Existing PRs/MRs are adopted without fabricated local-review evidence, and retries reuse a completed local phase instead of repeating it.
- **Explicit re-review stays available.** Invoking `/do:review` directly still requests a fresh review, with its verdict and attribution kept separate from the original pre-PR run.
- **Parallel workers register new files.** Remediation and dependency-removal workers add newly created owned files explicitly before their scoped commits, so new files are no longer left out.

## Fixed

- Preserve the pre-PR local review across delivery retries and resumed shipping.
- Continue existing PRs without recording local-review evidence that never happened.
- Keep hosted review pinned to the current head after the local phase resumes.
- Install and uninstall the new `pre-pr-review-lifecycle` shared procedure.
