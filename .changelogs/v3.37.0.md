# Release v3.37.0

Released: 2026-09-04

## Highlights

- **`/do:review` can now fix PRs on any host, not just GitHub.com.** It probes whether it actually has push access to the PR's head branch (own repo, or a fork with "allow edits from maintainers") and commits fixes directly when it does, falling back to inline review comments when it doesn't. New `--apply`/`--no-apply` flags override that routing, and `--merge` lands a clean PR once its blockers, mergeability, and required CI all check out.
- **GitLab checkouts no longer get silently misrouted to GitHub.** `/do:better`, `/do:depfree`, `/do:replan`, `/do:pr`, and `/do:next` now all derive the forge from the origin remote before checking any credentials, instead of trying `gh` first and only falling back to `glab` on failure — a real bug for anyone authenticated to both services. Enterprise/self-managed hosts, no-remote checkouts, and wrong-service-only credentials now all get an accurate, actionable error instead of writing to the wrong forge.
- **Wrapper commands work on non-Claude hosts.** `/do:prd`, `/do:simplify`, and `/do:pr-better` used to cite their delegated command with a Claude-specific file path, which didn't exist on a Codex-only install. Command references are now resolved per host, and a filtered install of a wrapper pulls in the command it delegates to.
- **Version-bump staging covers more ecosystems correctly.** `/do:better`'s version bump now only runs when the project actually has a versioned manifest (skips cleanly on Go or docs-only repos), dispatches per detected ecosystem instead of assuming Node, and correctly globs nested manifests (workspace `package.json`, multi-module `pom.xml`/`build.gradle`, nested Ruby gems). Rust's `cargo-release`/`cargo-set-version` invocations were also fixed to use their real flags.
- **Uninstalling or listing commands no longer strands wrapper commands.** A filtered `--uninstall` now refuses when another installed command still delegates to the one being removed, and `list()` correctly flags a command as unhealthy when its delegated dependency is missing, instead of reporting it as up to date.

## Added

- `/do:review --apply` / `--no-apply`: override automatic push-access routing for PR-mode fixes.
- `/do:review --merge`: merge a PR that came back clean from the review, gated on no unresolved blocker, mergeability, required CI, and an unmoved head.
- `lib/pr-write-access.md`: shared push-access probe (head-repo permission or fork `maintainerCanModify` + base push) used to route PR-mode fixes between direct commits and review comments.

## Fixed

- VCS host selection now derives from the origin remote before probing credentials, closing a mis-routing bug for GitLab checkouts with GitHub credentials also present (and the reverse), across `/do:better`, `/do:depfree`, `/do:replan`, `/do:pr`, and `/do:next`.
- PR/MR reference matching now checks URL shape instead of a `github.com` substring, so GitHub Enterprise and self-managed instances are recognized correctly, and GitLab MR URLs are rejected with a clear message instead of silently mismatching.
- `/do:better`'s version-bump step gates on the project actually having a versioned manifest, and stages nested/workspace manifests (npm/yarn workspaces, multi-module Java/Kotlin, nested Ruby gems) that were previously missed.
- Rust version bumps now call `cargo release version --execute` and `cargo set-version --bump <level>` correctly instead of arguments that were previously silent no-ops or invalid.
- `install()` refuses a filtered uninstall that would strand a wrapper command still depending on it; `list()` reports a command as unhealthy when its delegated dependency is missing rather than "up to date".
- Wrapper commands (`/do:prd`, `/do:simplify`, `/do:pr-better`) resolve their delegated command reference per installed host instead of a Claude-only path.
- `/do:fpr` derives its GitHub host from the origin remote instead of assuming github.com, matching `/do:release`'s existing host handling.

## Internal

- `/do:better` now loads audit guidance only for the currently active phase, reducing context load on long runs.
- Deferred prompt bundles are now shared across command hosts instead of being duplicated per environment.
