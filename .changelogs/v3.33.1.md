# Release v3.33.1

Released: 2026-08-18

## Highlights

- **`claude~effort` no longer derails the in-process reviewer.** Under Claude Code, a pinned reasoning effort now stays on the existing prompt advisory instead of tempting the orchestrator to swap in `/code-review`, which used to fill the merge gate with a verdict the loop never parsed.

## In-process Claude reviewer

- Step 2 of the local-agent loop now states that `{REVIEW_EFFORT}` has no `Agent`-tool parameter: it rides the `Target reasoning effort level` sentence already built into `$LOCAL_PROMPT`.
- The same step names the failure mode not to take: do not invent an `effort` argument, do not shell out to `claude -p --effort` (the API-billed path this branch exists to avoid), and do not substitute Claude Code's built-in `/code-review` skill for `$LOCAL_PROMPT`.
- Pre-flight now names all three effort carriers — CLI `--effort`, Cursor's `--model` fold, and prompt-only in-process — instead of the blanket "passed as `--effort` where supported".
