# Release v4.3.5

Released: 2026-11-02

## Highlights

- **Epic completion sees every child.** On GitHub, an epic's children are now resolved from native sub-issues *and* the `Part of #N` / epic-body task-list convention together. Previously, whichever source answered first hid the other, so an epic mixing the two could look done when its last visible child closed.
- **Failed sub-issue lookups no longer look like "no children."** A real lookup failure marks child resolution unresolved instead of silently falling back, so an epic is never closed on a partial child set.
- **New children get both links.** Filing a child under an epic now writes the `Part of #N` back-reference and a best-effort native sub-issue link, never `Closes #N` and never `replace_parent`.

## Fixed

- Union native sub-issues with `Part of` links when resolving epic children in `/do:next` and `/do:replan`.
