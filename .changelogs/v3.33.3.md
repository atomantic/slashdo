# Release v3.33.3

Released: 2026-08-23

## Highlights

- **Opted-in unattended updates are hardened without changing their behavior.** The SessionStart updater now resolves the explicit npm `latest` dist-tag to one exact version, invokes npm/npx without shell interpolation, disables package lifecycle scripts, and verifies that the requested version was actually installed.
- **The npm and curl installers now share more of their safety-critical behavior.** Settings hook registration, file synchronization, path handling, exit-status reporting, and cleanup are aligned so both install paths fail honestly and recover cleanly.
- **Large audit workflows are more maintainable and reliable.** The shared `/do:better` pipeline phases are now sourced from reusable library partials, with contract tests protecting substitution, output, and phase ordering.
- **Cross-platform behavior is better covered.** Statusline subprocess handling, CRLF frontmatter, test discovery, OpenCode temporary files, and Windows update-hook execution now have targeted fixes or tests.

## Fixed

- Auto-update no longer follows a mutable package tag at install time, accepts malformed registry output, executes package lifecycle hooks, or reports success when the installed marker stayed on an older version. Concurrent sessions remain serialized, stale locks are recoverable, and manual `/do:update` remains the fallback.
- npm-free and npx-free installations now report a useful update-check state instead of silently claiming to be current; pending unappliable updates continue to warn and re-warn when their cause changes.
- The curl installer fetches its sources from GitHub rather than trusting the caller's working directory, preserves custom Claude paths, cleans interrupted temporary state, and reports write failures accurately while remaining usable offline.
- Installer and uninstaller exit-code contracts now distinguish successful no-ops from failures, and the last untested lock and cleanup branches are covered.
- OpenCode temporary files are isolated and removed on transform failure; statusline hooks handle broken stdin and bounded subprocess checks without breaking session startup.
- Shared command content no longer loses instructions during substitution, and GH-host includes are guarded by the modes that support them.

## Changed

- Settings hook registration is implemented once and reused by npm and curl installs.
- Environment help and path rewriting are derived from the environment configuration, and obsolete version-check code and dead inline-library exports have been removed.
- CI now grants its token only the contents permission it needs, and the release action is pinned to an immutable commit.
- `/do:pr-better` documents its forwarded review flags, and the shared better-pipeline contracts now enforce the intended phase structure.

## Tests

- The release range adds installer end-to-end coverage, cleanup and lock-branch coverage, shared-pipeline contract tests, statusline pipe tests, cross-platform test discovery, CRLF frontmatter coverage, and the complete unattended-update hardening suite.
- CI passed on Node 18, 20, and 22 plus ShellCheck for this release PR.
