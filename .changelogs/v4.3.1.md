# Release v4.3.1

Released: 2026-10-24

## Highlights

- **Keep local validation focused.** PR and issue workflows follow the repository's local gate and run focused checks while hosted CI remains responsible for required broad coverage.
- **Protect parallel work.** Remediation workers commit only their owned files, review fixes sharing a file stay together, and audit PRs preserve shared foundation changes without bumping release versions.
- **Keep review fixes scoped.** Reviews distinguish defects in affected code from unrelated pre-existing issues, and encode conventions only for recurring architectural patterns.
- **Preserve uncertain backlog work.** Autonomous replanning comments on and labels likely-complete or stale issues instead of closing them without confirmation.

## Fixed

- Retain current-head checks, configured reviews, and merge safety gates when using focused local validation; focused results never stand in for suites that were not run.
- Avoid sweeping sibling workers' staged changes into remediation commits and defer unrelated in-progress build failures to final full-tree verification.
- Preserve shared foundation files in per-category audit branches and leave version bumps to release workflows.
- Restrain default dependency audits from hand-writing complex parsers and validators unless a native runtime API covers the used behavior within the existing size budget.
- Bound dependency lookups in safety scans and report incomplete coverage when their rate-limit budget is reached.
- Re-establish worktree paths and shell variables explicitly across tool calls so harness differences do not redirect issue work.
