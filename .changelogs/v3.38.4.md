# Release v3.38.4

Released: 2026-09-16

## Highlights

- **`--review-with agy[<model>]~effort=<level>` now resolves to the model you asked for.** A bare base model name plus an effort level (e.g. `agy[gemini-3.8-flash]~effort=low`) used to miss the level-picking step entirely and silently fall back to the roster default — a different model at a different level. The loop now completes a bare base against its leveled roster siblings first, and only falls back when that base has no entries at all.
- **Effort applies no matter how the model family was picked.** Whether the family came from an exact roster match, a base completion, or the roster default, `~effort` now selects the level — so an exact match or a model-less run keeps the effort you configured instead of dropping it.
- **`/do:config` documents the bare-base `--review-models agy=…` default.** Saving `agy=gemini-3.8-flash` without a level suffix is supported and gets completed at run time, not a stale-name hazard.

## Fixed

- `lib/local-agent-review-loop.md`: split agy model resolution into exact match → same-base leveled completion → roster default, then apply `{REVIEW_EFFORT}` to whichever family was picked, and report the resolution when the final pick differs from the request (3eebdd9, 406cdd6).
- `commands/do/config.md`: document bare-base `agy` entries in `--review-models`, and fix a flag-syntax typo in that note (3eebdd9, 406cdd6).
- `test/review-loop-contract.test.js`: pin the new resolution contract, including that effort application is not confined to the base-completion branch (3eebdd9, 406cdd6).
