# Release v3.28.1

Released: 2026-08-14

## Internal
- `/do:push` no longer treats `PLAN.md` as the file to check when deciding what documentation needs updating. It now reads the target repo's `CLAUDE.md`/`AGENT.md`/`AGENTS.md` for documentation conventions and only touches `PLAN.md` when one exists and is relevant.
