# Release v4.1.0

Released: 2026-10-17

## Highlights

- **`/do:depfree --extreme` aims at zero dependencies.** A new mode above `--heavy` that forces the strongest model tier at maximum reasoning effort, drops the replacement line ceiling in favor of a parity-test gate, and treats even web frameworks, UI libraries, client SDKs, ORMs and parsers as candidates when their used surface can be rebuilt. Only the runtime and its toolchain, security-sensitive protocol and primitive implementations, native bindings, and CI-required tooling stay exempt.
- **Conflict-free branches ship without a mandatory base rebase.** `/do:pr`, `/do:pr-better`, `/do:next` and the swarm no longer fast-forward and rebase onto the default branch on every run; a rebase happens only for an actual conflict, an enforced up-to-date requirement, or evidenced semantic overlap.

## Added

- `/do:depfree --extreme`: a `default` < `heavy` < `extreme` mode order recorded in `docs/DEPS.md`, prior decisions reused only at an equal or stricter mode, `SKIPPED_INFEASIBLE` rows re-tested on every extreme run, a written replacement design for any Complex-or-larger swap, one package per agent with at most three in flight, a second heavy-tier parity review, and a filed issue with a design sketch for anything the mode still cannot remove. `--interactive --extreme` skips the model-profile question rather than offering a cheaper tier.

## Fixed

- Review and merge against `origin/{default_branch}` by merge-base instead of touching the local default branch; rerun affected validation, required reviews and required checks only when HEAD actually changes; use `--force-with-lease` only after published history was rewritten.
- The merge gate states that it never updates the branch and that only the `MERGED` read-back counts as success; next-flow re-syncs run only when base-only commits touch files the branch changes.

## Internal

- Contract tests pin the extreme-mode flag, its forced model tier, the parity gate in the remediation brief, the exempt security classes, and the DEPS.md mode order.
- A git fixture proves a three-dot diff excludes base-only commits with HEAD unchanged.
