# Release v4.2.0

Released: 2026-10-22

## Highlights

- **Human reviewers get a human-length wait.** An `@<login>` reviewer that isn't a `[bot]` account is presumed to be a person: slashdo now waits up to 4 hours (polling every 30s for 5 minutes, then every 60s) instead of 15 minutes. Bot reviewers keep the short window. A review that doesn't arrive in time leaves the PR open with the request pending, and the "awaiting @login" state is documented so a host can resume once the reviewer responds.
- **Node.js 26.** The repo's pins, CI and publish workflows move to the Node 26 line, and the test matrix covers the supported lines 22, 24 and 26. The `engines` floor is unchanged, so existing consumers are not dropped.
