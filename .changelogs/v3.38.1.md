# Release v3.38.1

Released: 2026-09-11

## Highlights

- **`/do:release` now defers to a project's own documented release procedure.** When a repo documents its own release preparation and publication (e.g. a version-bump PR into `main`, tag-triggered publication, or a release-automation tool), `/do:release` follows that documented path instead of forcing the generic branch-promotion recipe (temporary release branch, self-PR guard) onto a topology that doesn't use it.
- **Dependency bump.** `softprops/action-gh-release` updated from 3.0.2 to 3.0.3 in the release workflow.

## Fixed

- `/do:release` selects the project's documented release procedure before mutating branches, instead of assuming every repo uses source→target branch promotion.

## Changed

- `.github/workflows/release.yml`: bump `softprops/action-gh-release` to 3.0.3 (#251).
