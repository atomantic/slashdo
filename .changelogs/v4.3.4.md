# Release v4.3.4

Released: 2026-10-30

## Highlights

- **Release and merge gates no longer merge on an empty "required checks" report.** When the forge requires status checks that have not registered yet, the merge gate now keeps waiting (up to 30 minutes) instead of treating the empty report as success. Verified absence of required checks is still accepted, and branch rules are paginated and queried against the resolved GitHub host (including Enterprise).
- **CI reruns are smarter.** The flake-handling routine reads the failed job's log before spending its single rerun.
- **Pre-push gate is focused.** The repo's focused pre-push gate is required while broad CI stays opt-in.
- **Command snippets are safe under skill hosts.** Shell helpers in the command and lib docs now take their inputs from named variables rather than positional parameters, which skill hosts expand in place; a contract test enforces this.
- **Tool-free review mode is optional,** not an availability gate.

## Fixed

- Required-check detection in the merge gate and release CI gate (late registration, classic-protection absence, paginated branch rules, resolved GitHub host).
- Read the failed job log before the one CI rerun.
- Require the focused pre-push gate; keep broad CI opt-in.
- Replace positional parameters in command snippets with named variables.
- Treat tool-free review mode as optional rather than an availability gate.
