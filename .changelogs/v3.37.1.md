# Release v3.37.1

Released: 2026-09-05

## Highlights

- **`/do:next`'s dependency on `/do:pr` is now enforced.** `do:next`'s ship phase invokes `/do:pr` in prose only, which the dependency scanner didn't recognize as a citation — so a filtered install could skip `do:pr` while still installing `do:next`, and `--uninstall pr` could silently break `do:next`'s ship phase. `do:next` now cites `do:pr` with the standard execution-reference form so it's auto-installed and protected like any other dependency.

## Fixed

- `commands/do/next.md` cites `~/.claude/commands/do/pr.md` with the standard execution reference, closing the gap where dependency detection missed a genuine runtime dependency expressed only in prose (#241).

## Internal

- Broadened `CONTRIBUTING.md`'s citation-form contract to cover any command with a genuine runtime dependency, not just the three full-workflow wrapper commands.
