# Release v3.38.2

Released: 2026-09-14

## Highlights

- **`agy` reviews no longer die on a dropped model tier.** The `--review-with agy` merge-gate slot now resolves its review model against agy's live roster instead of a hardcoded model name, so a roster change (like agy 1.2.2 dropping the "Gemini 3.5 Flash (High)" tier) degrades to the newest available Flash (High) model instead of failing the whole run outright.
- **Fixed a stray roster probe.** That same model-resolution check was firing on every reviewer pass (codex, claude, grok, cursor, pi), not just `agy` passes — it now only runs when the entry actually is `agy`.

## Fixed

- `lib/multi-reviewer-loop.md`: resolve the `agy` review model against its live roster instead of a dead literal, falling back to the newest Flash (High) tier and reporting the substitution (50a2d29).
- `lib/multi-reviewer-loop.md`: gate the `agy` roster probe on the entry's agent so it only fires for `agy` enhancement entries, not every reviewer (9f79723).
