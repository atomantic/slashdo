# Release v4.3.6

Released: 2026-11-08

## Highlights

- **Commands load without a global install.** A project that vendors slashdo and symlinks its commands (no `~/.claude/lib`) can now run them: each shared-library expansion falls back to the library beside the command's real location. A new test fails on any expansion that has no resolvable fallback.
- **Host-reviewer merges carry their merge procedure.** The GitHub and GitLab `merge` verbs now bundle the shared merge gate they depend on, so a deferred or skill-style install no longer reaches the merge step without its instructions.
- **Local reviewer sandbox stops tripping on timestamps.** The git-hooks integrity check now fingerprints each hook's path, type, executable bit, and content instead of tar metadata, which ends intermittent "git hooks restore failed" errors when only mtimes changed (seen on Node 26 CI).

## Fixed

- Resolve `~/.claude/lib` expansions in bundled-symlink installs, including the review PR-mode write-access partial (#509).
- Bundle the shared merge gate required by the host verb `merge` steps (#510).
- Fingerprint git hooks by path/type/exec-bit/content, not tar metadata, in the local CLI runner (#507).

## Internal

- Bump `softprops/action-gh-release` from 3.0.3 to 3.0.4.
