# Release v4.0.2

Released: 2026-10-04

## Highlights

- **Release preparation respects branch protection.** Protected development branches now receive version preparation and review fixes through PRs that satisfy their remote admission checks before promotion.
- **Issue labels use valid CLI arguments.** Label guidance now supplies complete creation commands with explicit colors, preventing color values from becoming accidental label names.

## Fixed

- Detect GitHub rulesets and classic branch protection before pushing release preparation, and resolve effective GitLab protection together with its pipeline requirements.
- Resume an existing preparation PR without bumping the version again, verify the exact pushed head, and read back merged state before opening the release promotion PR.
- Pin preparation merges to the head whose checks passed and route later review fixes through the same admission procedure.
- Include the release admission helper in both curl installer and uninstaller allowlists.
- Spell out label creation commands for plan, category, severity, model, effort, and drift labels, preserving GitLab color syntax.

## Internal

- Add regression coverage for label command syntax and protected-branch release admission, including malformed forge responses and false GitLab protection values.
- Keep shared issue setup guidance within the prompt bundle size budget.
